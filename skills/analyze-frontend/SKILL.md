# 前端项目深度分析

当用户调用此 Skill 时，读取同目录下的 `prompts/analysis.md`，把它当作你自己的工作指令，按其中的方法论和九章结构**自己执行**这次分析。

报告**必须完整呈现**给用户，不得省略、压缩或改写任何章节。即使报告很长，用户也期望看到完整的九章分析内容。如果输出被截断，分段继续。
